> Расширение **Translator3000** для игр на Ren'Py: перевод через OpenAI / ChatGPT, перевод интерфейса игры (меню и настройки), быстрое переключение режима прямо в игре, а также экспорт/импорт переводов — Выпускается в двух вариантах одним файлом: самостоятельный `Translator3000-openai.rpa` (оригинал + дополнение) или компактный `Translator3000-openai-addon.rpa`, который кладётся рядом с оригинальным `Translator3000.rpa`.

Translator3000 уже переводит диалоги игр на Ren'Py в реальном времени своими встроенными сервисами. Этот проект сохраняет оригинальный Translator3000 без изменений и добавляет поверх него новые возможности. Для другой игры достаточно скопировать 1 файл `.rpa` (самостоятельную сборку либо дополнение рядом с оригинальным `Translator3000.rpa`) в её папку `game`.

---

## ✨ Что добавлено по сравнению с оригинальным Translator3000

### 1. Перевод через OpenAI / ChatGPT

- Новый провайдер `openai_api`: перевод через OpenAI API или аккаунт ChatGPT, со своим API-ключом, Base URL, выбором модели (встроенный список моделей GPT) и уровнем reasoning effort.
- Пакетный перевод большими блоками с защитой тегов Ren'Py (`[переменные]`, `{теги}`, `%(...)s`) через плейсхолдеры, поэтому переведённые строки не ломают синтаксис игры.
- Подключение к собственной точке prescan у Translator3000: весь скрипт сканируется заранее, имеющиеся записи базы переиспользуются, на перевод отправляются только новые строки.
- Настройки OpenAI общие для всех игр на одном компьютере.

### 2. Перевод интерфейса игры — без правок под каждую игру

- Prescan также собирает текст из **каждого зарегистрированного экрана** Ren'Py (главное меню, Preferences, Settings, сохранение/загрузка…) напрямую из AST экранов — без жёстко прописанных строк, поэтому работает в любой игре.
- Переводы интерфейса хранятся в **той же базе данных**, что и диалоги, и создаются **тем же провайдером**.
- Отображение включается отдельной галочкой в настройках и следует режиму Translator3000: **Off** — исходный текст, **DB only / Prescan** — только поиск по базе, **Realtime** — живой перевод при отсутствии записи.
- По умолчанию игра всегда запускается на исходном языке.

### 3. Быстрое переключение режима Off ↔ DB only

- Постоянно видимый бейдж в правом верхнем углу экрана показывает текущий режим (`OFF: original`, `Mode: DB only`, …).
- Клик по бейджу или нажатие **Alt+1** (Option+1 на macOS) мгновенно переключает **Off ↔ DB only** — без выхода из текущей сцены и строки диалога и без изменения файла настроек.

### 4. Экспорт / импорт переводов

- Кнопки **Export translation** / **Import translation** в верхней части страницы настроек (Ctrl+`).
- Экспорт записывает `translations.tr3000.json` для резервной копии или переноса на другой компьютер. Импорт добавляет только недостающие строки; существующие локальные переводы сохраняются.

### 5. Дополнительно

- Блокировка принудительной проверки обновлений Translator3000 (`tr3000_disable_update.py`).
- Автоматическое вписывание переведённого текста в рамку (`tr3000_autofit.py`).
- Английские подписи для интерфейса настроек (`tr3000_ui.py`).

Всё из оригинального Translator3000 — панель Ctrl+`, режимы Off / Prescan / DB-only / Realtime и база переводов для каждой игры — продолжает работать без изменений. Дополнения только подключаются к этим существующим точкам.

## 🚀 Установка

1. Соберите пакет (см. [Сборка](#-сборка)) или возьмите готовый `build/Translator3000-openai.rpa`.
2а. Либо скопируйте `Translator3000-openai.rpa` в папку `game` нужной игры — в него уже включён оригинальный Translator3000.
2б. Либо, если в игре уже есть оригинальный `Translator3000.rpa`, скопируйте `build/Translator3000-openai-addon.rpa` рядом с ним: дополнение добавляет новые возможности поверх оригинала.
3. Запустите игру и нажмите **Ctrl+`**, чтобы открыть панель Translator3000.

> **Не** копируйте в игру также оригинальный `Translator3000.rpa` или отдельные файлы `.py` / `.rpy` — отдельные файлы перекрывают файлы внутри RPA. Ren'Py автоматически загружает каждый `.rpa` в папке `game`.

Первые две кнопки страницы настроек — **Export translation** и **Import translation** (в русском интерфейсе: **Экспорт перевода** / **Импорт перевода**).

## 📖 Использование

### Перевод игры

1. Нажмите **Ctrl+`** и настройте провайдер OpenAI (API-ключ, Base URL, модель).
2. Запустите **Prescan**, чтобы перевести весь скрипт (и текст интерфейса) в базу данных.
3. Выберите режим отображения:
   - **DB only** — показывать переводы, уже имеющиеся в базе (рекомендуется после prescan).
   - **Realtime** — переводить недостающие строки на лету.
   - **Off** — исходный язык.

### Перевод интерфейса игры

1. В настройках OpenAI (Ctrl+`) включите **«Переводить интерфейс игры (меню, настройки, подсказки)»**. По умолчанию галочка **снята**.
2. Запустите Prescan — строки экранов собираются и переводятся вместе с диалогами.
3. Выберите **DB only**, чтобы интерфейс отображался на целевом языке; выберите **Off**, чтобы вернуться к оригиналу.

### Быстрое переключение

- **Alt+1** (Option+1 на macOS) или клик по бейджу в правом верхнем углу переключает **Off ↔ DB only**. Если текущий режим — Prescan или Realtime, переключение переводит в Off.
- Переключение проходит через свойство `mode` у `translator3000._gui` — тот же механизм, что используют кнопки панели Ctrl+`, — поэтому панель и весь текст на экране обновляются одновременно. Файл настроек никогда не изменяется: после перезапуска игры по-прежнему действует `modeOnStartup`.

## 💾 Где хранятся данные

Используемые переводы находятся в папке пользователя:

```
vladya's projects database/translator3000/translations/<id сохранений игры>/
```

Id берётся из `config.save_directory` игры. Для той же игры, сервиса и пары языков prescan переиспользует существующие строки и переводит только новые.

Общие настройки OpenAI (API-ключ, Base URL, выборы) хранятся один раз для всех игр:

```
vladya's projects database/translator3000/_translator3000_openai.json
```

Настройки перевода интерфейса (`ui_translate_enabled`, `ui_max_chars`, `ui_debug`):

```
vladya's projects database/translator3000/_translator3000_ui.json
```

Установите `ui_debug` в `true`, чтобы записывать журнал перевода интерфейса (`_translator3000_ui_debug.log`, та же папка).

## 🔧 Сборка

Исходники мода находятся в `src/`. После их изменения пересоберите пакет:

```text
python build_rpa.py          # full: оригинал + дополнение -> build/Translator3000-openai.rpa
python build_rpa.py addon    # только дополнение          -> build/Translator3000-openai-addon.rpa
python build_rpa.py all      # оба варианта
```

Исходники мода находятся в `src/`. Полная сборка объединяет оригинальный `Translator3000.rpa` с перечисленными ниже файлами мода; сборка дополнения упаковывает только файлы мода, поэтому копируйте `Translator3000-openai-addon.rpa` рядом с имеющимся оригинальным `Translator3000.rpa`:

- `zzz_translator3000_openai.rpyc`
- `tr3000_openai.py`
- `tr3000_ui.py`
- `tr3000_ui_translate.py`
- `tr3000_mode_toggle.py`
- `tr3000_autofit.py`
- `tr3000_disable_update.py`
- `tr3000_transfer.py`

> Ren'Py не выполняет файлы `.rpy` внутри RPA. Скрипт экранов должен быть скомпилированным `zzz_translator3000_openai.rpyc`, собранным **той версией Ren'Py, что у целевой игры**: поместите `.rpy` в папку `game`, один раз запустите игру, затем скопируйте созданный `.rpyc` обратно сюда. Для изменений только в `.py` достаточно `python build_rpa.py`.

### Как работает модуль интерфейса

`tr3000_ui_translate.py` — отдельный модуль; его загрузчик находится внутри `zzz_translator3000_openai.rpy` (отдельного файла-загрузчика нет):

- **Prescan всегда сканирует текст интерфейса**: строки собираются из всех зарегистрированных экранов Ren'Py, добавляются к обычному списку prescan у Translator3000, переводятся тем же провайдером и сохраняются в ту же базу данных. Ничего не прописано под конкретную игру.
- **Отображение — по выбору**: галочка в настройках по умолчанию снята, поэтому интерфейс показывает исходный язык. Когда она включена, отображение следует режиму Translator3000: Off — оригинал, DB-only/Prescan — только база, Realtime — плюс живой перевод.

`tr3000_mode_toggle.py` — отдельный модуль, потому что переключение режима влияет и на диалоги, а не только на интерфейс: в нём находятся `current_mode()`, `set_mode()`, `toggle_db_only()` и `mode_label()`, используемые экраном бейджа и горячей клавишей Alt+1.

Приветствуются issue и pull request'ы. Если в какой-то игре интерфейс не переводится, включите `ui_debug` и приложите к отчёту соответствующие строки из `_translator3000_ui_debug.log`.
